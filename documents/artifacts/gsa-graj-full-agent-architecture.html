Key Data Flows
User→gsa_graj_agent
Text prompt or Excel file attachment. Agent selects and calls the appropriate tool.
User→gsa_graj_viz_agent
Natural-language chart request. Agent inspects schema, composes SQL, validates, runs, and renders markdown chart.
User→gsa_graj_eval_agent
Trigger full or filtered benchmark run. Eval agent delegates questions to gsa_graj_agent and judges responses.
gsa_graj_agent→gsa_graj_tools (MCP)
streamable_http to Code Engine. 9 tools: schema inspect, read, write, aggregate, count, query, weather, joke, unit.
gsa_graj_agent→gsa_graj_viz (MCP)
Calls gsa_graj_viz_redact_pii before displaying any row data containing PII columns.
gsa_graj_viz_agent→gsa_graj_viz (MCP)
streamable_http to Code Engine. 6 tools: inspect → preview → run → redact PII → build chart → export CSV.
gsa_graj_bulk_excel_to_sl→wxodb (PostgreSQL)
WXOFile bytes from chat window → openpyxl → pg8000 INSERT. Auto-creates table. append / replace modes.
gsa_graj_load_excel_to_postgres→wxodb (PostgreSQL)
Same WXOFile flow. Normalises column headers to lowercase_underscore. append / replace modes.
gsa_graj_viz_redact_pii→Agent (in-process)
Pure in-memory transform. Scans column names + cell values. Returns redacted JSON payload. No DB call.
gsa_graj_tools (MCP)→wttr.in / icanhazdadjoke
httpx GET · no redirects · 10 s timeout · no env proxy · no auth required.
gsa_graj_eval_agent→gsa_graj_agent (collaborator)
Sends each dataset question to the agent under test and captures the full response for judging.
eval tools→gsa-graj-eval-0.csv

Regex match on column names:
name · email · phone · dob · ssn · patient_id · address · gender · attending_doctor · salary · national_id · iban · passport · license · race · ethnicity · biometric · ip_address …
LEVEL 2 — Cell Value Scan
Regex patterns on each cell value:
email · phone · SSN · credit card · IP address · DOB date · UK NHS number · UK postcode · US ZIP code
OUTPUT
redacted rows

+ redacted_cells count
